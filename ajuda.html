Perguntas frequentesFrequently asked questions

O YouTube responde “403 Forbidden” no download.YouTube answers “403 Forbidden” on download.
A imagem já inclui o necessário e atualiza o yt-dlp na partida (desligue com BNP_YTDLP_AUTOUPDATE=false). Se persistir, renove os cookies com /bnp-youtube-cookies.
The image already includes what’s needed and updates yt-dlp on start (turn off with BNP_YTDLP_AUTOUPDATE=false). If it persists, refresh the cookies with /bnp-youtube-cookies.
Recebo 429 ao baixar legendas.I get 429 when downloading subtitles.
O servidor e o plugin de PO token precisam estar na mesma versão principal. Use a imagem mais recente, que os mantém alinhados.
The PO token server and plugin must share the same major version. Use the latest image, which keeps them aligned.
A máquina trava ou o FFmpeg estoura a memória.The machine freezes or FFmpeg runs out of memory.
Reduza o paralelismo: BNP_FFMPEG_MAX_CONCURRENT (padrão: metade dos núcleos), BNP_FFMPEG_THREADS e BNP_MAX_CONCURRENT_JOBS. Os jobs excedentes esperam na fila e começam sozinhos.
Lower the parallelism: BNP_FFMPEG_MAX_CONCURRENT (default: half the cores), BNP_FFMPEG_THREADS and BNP_MAX_CONCURRENT_JOBS. Extra jobs wait in the queue and start by themselves.
As ferramentas não aparecem no agente.The tools don’t show up in the agent.
Reabra o agente depois do registro e confira o comando de registro: o -i é obrigatório e o .env precisa existir no caminho informado.
Reopen the agent after registering and check the register command: -i is required and the .env must exist at the given path.
O painel diz “Acesso remoto bloqueado”.The panel says “Remote access blocked”.
Nenhum login foi criado. Abra http://localhost:7420 no próprio computador e crie o login em Primeiro acesso. Só depois o painel aceita outros aparelhos.
No login has been created. Open http://localhost:7420 on the machine itself and create the login under First access. Only then does the panel accept other devices.
No celular: “Sua conexão não é particular”.On mobile: “Your connection is not private”.
O certificado ainda não foi instalado como CA no aparelho (não como certificado de VPN/app). Refaça o passo 2 do modal Celular.
The certificate hasn’t been installed as a CA on the device (not as a VPN/app certificate). Redo step 2 of the Phone modal.
No celular o endereço não abre.On mobile the address doesn’t open.
Celular e computador precisam estar na mesma rede Wi-Fi (sem isolamento de clientes) e o firewall deve liberar as portas 7420 e 7443. Com Docker em rede bridge, abra o painel pelo IP do computador (não localhost) ou fixe BNP_LAN_HOST; no Linux, --network host dispensa isso.
Phone and computer must be on the same Wi-Fi (no client isolation) and the firewall must allow ports 7420 and 7443. With Docker in bridge mode, open the panel by the computer’s IP (not localhost) or set BNP_LAN_HOST; on Linux, --network host avoids this.
“Instalar app” ou “Compartilhar” não aparecem.“Install app” or “Share” don’t appear.
É preciso abrir o painel pelo endereço HTTPS ao menos uma vez. O compartilhamento só aparece com o app instalado e só no Android/Chrome.
You need to open the panel at the HTTPS address at least once. Sharing only appears once the app is installed, and only on Android/Chrome.
O vídeo vertical sai com o enquadramento errado.The vertical video comes out badly framed.
O smart reframe usa detecção de rosto local. Sem rosto detectado, ele centraliza o corte. Confirme que o reframe está ativado no pedido e que o locutor aparece de frente.
Smart reframe uses local face detection. With no face detected, it centers the crop. Check that reframe is on in the request and that the speaker faces the camera.
A autenticação do YouTube ou do Instagram expirou.YouTube or Instagram sign-in expired.
Rode /bnp-youtube-auth ou /bnp-instagram-auth. Para o perfil de desempenho, a conta precisa do escopo de Analytics (YouTube) ou da permissão de Insights (Instagram).
Run /bnp-youtube-auth or /bnp-instagram-auth. For the performance profile, the account needs the Analytics scope (YouTube) or the Insights permission (Instagram).
Licença: o painel abre, mas nenhum vídeo é gerado.License: the panel opens, but no video is generated.
Abra Primeiros passos ou Licença e acesso remoto no painel e leia o estado (o log do container mostra o mesmo): MISSING (sem licença: envie o código deste computador e cole o token recebido), INVALID (token adulterado, outra instalação ou relógio voltado), EXPIRED (venceu, ou ficou mais de 14 dias sem checar o status) e REVOKED (revogada). Confira o mesmo volume /app/data e o acesso à internet.
Open Getting started or License and remote access on the panel and read the state (the container log shows the same): MISSING (no license: send this computer’s code and paste the token you get), INVALID (tampered token, another installation or clock set back), EXPIRED (it ran out, or went over 14 days without checking status) and REVOKED. Check the same /app/data volume and internet access.
Primeiro acesso: o painel pede um código.First access: the panel asks for a code.
É o caso do Docker com -p: o navegador não chega como localhost, então o primeiro login exige o código que o container imprime. Rode docker logs <nome-do-container> 2>&1 | grep "primeiro acesso" ou docker exec <nome-do-container> cat /app/data/setup-code. Maiúsculas, espaços e hífens não importam. Depois de 5 tentativas erradas, espere 15 minutos. O código some quando o login é criado. Esqueceu a senha? Ajuste BNP_LOGIN_* no /app/data/.env.
This is the case for Docker with -p: the browser doesn’t arrive as localhost, so the first login requires the code the container prints. Run docker logs <container-name> 2>&1 | grep "primeiro acesso" or docker exec <container-name> cat /app/data/setup-code. Case, spaces and hyphens don’t matter. After 5 wrong attempts, wait 15 minutes. The code goes away once the login is created. Forgot the password? Adjust BNP_LOGIN_* in /app/data/.env.
Código 77 na partida.Exit code 77 on start.
O ambiente foi considerado adulterado: agente Java (-javaagent), depuração, LD_PRELOAD ou arquivos alterados. Use a imagem oficial sem opções extras de JVM.
The environment was considered tampered with: a Java agent (-javaagent), debugging, LD_PRELOAD or modified files. Use the official image with no extra JVM options.
