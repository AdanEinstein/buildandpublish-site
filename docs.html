From image access to your first published video. Questions along the way? See the Help.

Início rápidoQuick start

  1. Peça sua licença em Contato e receba as credenciais do registry privado.Request your license at Contact and receive the private registry credentials.
  2. Entre no registry e baixe a imagem.Sign in to the registry and pull the image.
  3. Suba o container e abra o painel em http://localhost:7420. Não precisa de .env nem de licença para isso.Start the container and open the panel at http://localhost:7420. No .env or license needed for that.
  4. Crie o login. O painel pede o código de primeiro acesso, que está no log do container.Create your login. The panel asks for the first access code, which is in the container log.
  5. Em Primeiros passos, copie o código deste computador (fingerprint), envie e cole o token da licença que receber.In Getting started, copy this computer’s code (fingerprint), send it and paste the license token you receive.
  6. Ali mesmo, conecte a IA e as contas. Depois registre no agente e peça o primeiro vídeo.Right there, connect the AI and your accounts. Then register with your agent and ask for your first video.

Docker

echo "<token-do-registry>" | docker login ghcr.io -u <usuario> --password-stdin docker pull ghcr.io/adaneinstein/buildandpublish-pro:latest

A imagem inclui FFmpeg, yt-dlp e o plugin de PO token. Use -i para manter o STDIN aberto (servidor MCP) e um volume em /app/data: ele guarda histórico, arquivos de trabalho e a identidade da instalação.

The image includes FFmpeg, yt-dlp and the PO token plugin. Use -i to keep STDIN open (MCP server) and a volume at /app/data: it holds history, working files and the installation identity.

Para a primeira configuração, suba o painel em segundo plano e pegue o código de primeiro acesso no log:

For the first setup, start the panel in the background and get the first access code from the log:

docker run -d -i --name bnp -v bnp-data:/app/data \ -p 7420:7420 -p 7443:7443 \ ghcr.io/adaneinstein/buildandpublish-pro:latest docker logs bnp 2>&1 | grep "primeiro acesso"

Sem licença o container sobe só para você configurá-lo: nenhum vídeo é gerado até a licença ser colada no painel. Tudo o que você salva no painel (login, licença, chaves) fica no volume e vale para os próximos containers. As portas 7420 e 7443 também servem para abrir o painel pelo celular. Terminou de configurar? docker rm -f bnp e registre no agente.

With no license the container starts only so you can set it up: no video is generated until the license is pasted in the panel. Everything you save in the panel (login, license, keys) lives in the volume and carries over to later containers. Ports 7420 and 7443 also let you open the panel from your phone. Done setting up? docker rm -f bnp and register with your agent.

Comandos /bnp-*/bnp-* commands

A execução é assíncrona: o disparo devolve um jobId e você acompanha com /bnp-status. Sem os atalhos instalados, peça ao agente em linguagem natural: ele usa as mesmas ferramentas MCP.

Execution is asynchronous: starting returns a jobId and you follow it with /bnp-status. Without the shortcuts installed, ask the agent in plain language: it uses the same MCP tools.

Exemplo de pedidoExample request

/bnp-youtube-shorts - Formato vertical, 10 trechos de até 90 segundos - Smart reframe seguindo o locutor - Thumbnail chamativa com a marca do canal - Publicar amanhã às 12:00 no fuso do sistema - Se faltar algum dado obrigatório, peça só o mínimo

Quando a conta tem acesso ao Analytics, o pipeline olha os conteúdos de maior audiência dos últimos 90 dias e usa os padrões nos cortes, títulos e roteiros. Se aparecer “sem acesso”, reautentique.

When the account has Analytics access, the pipeline looks at your top content from the last 90 days and uses the patterns in cuts, titles and scripts. If you see “no access”, sign in again.

Painel webWeb panel

Sobe sozinho junto com o servidor MCP em http://localhost:7420. Crie o login em Primeiro acesso e siga Primeiros passos: licença, IA (chave de um provedor ou um CLI já logado no computador, como Claude Code, OpenCode ou Antigravity) e contas. Ali você dispara pipelines em Novo pipeline, acompanha jobs em tempo real, configura contas e armazenamento, e usa Clonar e editar para repetir um job mudando só o necessário.

It starts with the MCP server at http://localhost:7420. Create your login under First access and follow Getting started: license, AI (a provider key or a CLI already logged in on the computer, such as Claude Code, OpenCode or Antigravity) and accounts. There you start pipelines in New pipeline, follow jobs live, configure accounts and storage, and use Clone and edit to repeat a job changing only what you need.

Sem login configurado, o painel recusa acessos que não sejam do próprio computador. A exceção é criar o login com o código de primeiro acesso do log (é o caso do Docker com -p, em que o navegador não chega como localhost). O código vale uma vez e para de funcionar quando o login é criado. A IA local por CLI não roda dentro do Docker.

With no login configured, the panel refuses any access that doesn’t come from the machine itself. The exception is creating the login with the first access code from the log (the case for Docker with -p, where the browser doesn’t arrive as localhost). The code works once and stops working when the login is created. Local AI through a CLI doesn’t run inside Docker.

LicençaLicense

Sem licença válida, o container sobe só com o painel: nenhum vídeo é gerado. O fingerprint da instalação aparece em Primeiros passos (e no log). Cole o token ali, ou informe por BNP_LICENSE_KEY, ou salve em /app/data/license.key. O token colado no painel vale sem reiniciar.

Without a valid license, the container starts with the panel only: no video is generated. The installation fingerprint shows in Getting started (and in the log). Paste the token there, or provide it through BNP_LICENSE_KEY, or save it at /app/data/license.key. A token pasted in the panel works without a restart.

Mantenha o mesmo volume em /app/data: ele guarda a identidade da instalação. O container precisa alcançar a internet ao menos uma vez a cada 14 dias para renovar o status da licença. O painel mostra o estado atual da licença.

Keep the same volume at /app/data: it holds the installation identity. The container needs internet access at least once every 14 days to renew the license status. The panel shows the current license state.
