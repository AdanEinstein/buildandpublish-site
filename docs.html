From image access to your first published video. Questions along the way? See the Help.

Início rápidoQuick start

  1. Peça sua licença em Contato e receba as credenciais do registry privado.Request your license at Contact and receive the private registry credentials.
  2. Entre no registry e baixe a imagem.Sign in to the registry and pull the image.
  3. Suba o container uma vez sem licença: ele imprime o fingerprint e encerra.Start the container once with no license: it prints the fingerprint and exits.
  4. Envie o fingerprint e receba o token da licença.Send the fingerprint and receive the license token.
  5. Suba de novo informando o token, registre no agente e peça o primeiro vídeo.Start again with the token, register with your agent and ask for your first video.

Docker

echo "<token-do-registry>" | docker login ghcr.io -u <usuario> --password-stdin docker pull ghcr.io/adaneinstein/buildandpublish-pro:latest

A imagem inclui FFmpeg, yt-dlp e o plugin de PO token. Use -i para manter o STDIN aberto (servidor MCP) e um volume em /app/data: ele guarda histórico, arquivos de trabalho e a identidade da instalação.

The image includes FFmpeg, yt-dlp and the PO token plugin. Use -i to keep STDIN open (MCP server) and a volume at /app/data: it holds history, working files and the installation identity.

docker run -i --rm --env-file .env -v bnp-data:/app/data \ -e BNP_LICENSE_KEY="<token>" \ ghcr.io/adaneinstein/buildandpublish-pro:latest

Para abrir o painel pelo celular, publique as portas 7420 e 7443 (-p 7420:7420 -p 7443:7443).

To open the panel from your phone, publish ports 7420 and 7443 (-p 7420:7420 -p 7443:7443).

Comandos /bnp-*/bnp-* commands

A execução é assíncrona: o disparo devolve um jobId e você acompanha com /bnp-status. Sem os atalhos instalados, peça ao agente em linguagem natural: ele usa as mesmas ferramentas MCP.

Execution is asynchronous: starting returns a jobId and you follow it with /bnp-status. Without the shortcuts installed, ask the agent in plain language: it uses the same MCP tools.

Exemplo de pedidoExample request

/bnp-youtube-shorts - Formato vertical, 10 trechos de até 90 segundos - Smart reframe seguindo o locutor - Thumbnail chamativa com a marca do canal - Publicar amanhã às 12:00 no fuso do sistema - Se faltar algum dado obrigatório, peça só o mínimo

Quando a conta tem acesso ao Analytics, o pipeline olha os conteúdos de maior audiência dos últimos 90 dias e usa os padrões nos cortes, títulos e roteiros. Se aparecer “sem acesso”, reautentique.

When the account has Analytics access, the pipeline looks at your top content from the last 90 days and uses the patterns in cuts, titles and scripts. If you see “no access”, sign in again.

Painel webWeb panel

Sobe sozinho junto com o servidor MCP em http://localhost:7420. Crie o login em Primeiro acesso. Ali você dispara pipelines em Novo pipeline, acompanha jobs em tempo real, configura contas e armazenamento, e usa Clonar e editar para repetir um job mudando só o necessário.

It starts with the MCP server at http://localhost:7420. Create your login under First access. There you start pipelines in New pipeline, follow jobs live, configure accounts and storage, and use Clone and edit to repeat a job changing only what you need.

Sem login configurado, o painel recusa acessos que não sejam do próprio computador.

With no login configured, the panel refuses any access that doesn’t come from the machine itself.

LicençaLicense

Sem licença válida, a imagem imprime o fingerprint da instalação e encerra. O token é informado por BNP_LICENSE_KEY ou salvo em /app/data/license.key.

Without a valid license, the image prints the installation fingerprint and exits. The token is provided through BNP_LICENSE_KEY or saved at /app/data/license.key.

Mantenha o mesmo volume em /app/data: ele guarda a identidade da instalação. O container precisa alcançar a internet ao menos uma vez a cada 14 dias para renovar o status da licença. O painel mostra o estado atual da licença.

Keep the same volume at /app/data: it holds the installation identity. The container needs internet access at least once every 14 days to renew the license status. The panel shows the current license state.
